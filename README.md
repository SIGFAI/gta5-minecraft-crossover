# Minecraft Crossover

**gta5** × Minecraft · visual · idea by the team

GTA V and Minecraft run live together: Minecraft blocks and creatures appear inside Los Santos and react to the player. The change shows in the first 30 seconds of play.

> I dropped Minecraft into Los Santos: a creeper-face wall, zombies hunting pedestrians, and a wrecked car that lights Minecraft TNT.

## Install

Needs GTA V (story mode, offline only) with ScriptHookV and ReShade, plus Minecraft Java with Fabric. Copy the mod's GTA files into the GTA folder and its Minecraft jar into the mods folder, start both games, load story mode, and walk around Los Santos.
